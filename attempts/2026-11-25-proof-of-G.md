# 2026-11-25 - Proof of hypothesis (G) of C013 by the circle method (prover)

## Goal

Prove (G\*): for fixed A, with Y = Z/(log Z)^2,
#{h <= Z even : |R_Y(h) - S(h)Y| > Y (log Z)^{-A}} ≪_A Z (log Z)^{-A}.
Then deduce hypothesis (G) of C013, which by C013 (d) (skeptic PASS) would give the permutation property. The result is to be a new candidate, C014.

## Idea

Route B of `literature/search-C013-G-and-cascade.md`: the classical Goldbach-exceptional-set circle method (Chudakov / van der Corput / Estermann; Vaughan's book Ch. 3), for the difference problem with unbalanced lengths.
- R(h) = ∫ G \bar F e(-hα), with F of length Y and G of length N = Z + Y. This identity is exact for 1 <= h <= Z.
- Bessel/Parseval reduces everything to L^2 bounds on arcs.
- Minor arcs: sup |G| (Vinogradov) times ∫|F|^2.
- Major arcs: Siegel-Walfisz for F and G pointwise.
- Main term: S_P(h) times a singular integral.
- Tail: an elementary mean-square bound for S - S_P.

Route A (Lavrik) was not used: its exact statement is still unread, and the task said to prefer the route whose inputs can be stated precisely.

## Work

1. **Choice of arcs (the one real design decision).**
   - First try: arcs |α - a/q| <= 1/(qQ) with Q = N/P. Then the singular integral ∫_{|β|<=P/(qN)} v_N \bar v_Y e(-hβ) is **not** close to ⌊Y⌋ for q close to P. The arc width P/(qN) is then about 1/N, far below 1/Y, and the tail of the integral is of size min(Y log L, N q/P), i.e. as large as the main term.
   - Pointwise this kills the argument. In mean square it might survive, but it is messy.
   - Fix: arcs of **uniform** width δ = P/N for all q <= P (as in Vaughan's Goldbach chapter). Then δY ≍ L^{B-2}, and the singular integral is ⌊Y⌋ + O(N/P) uniformly in q. The main term is exactly S_P(h)·(⌊Y⌋ - τ(h)).
   - Disjointness needs N > 2P^3.
   - Minor arcs: Dirichlet with Q' = ⌊N/P⌋ still forces q > P on the complement, so Vinogradov gives sup_m |G| ≪ N P^{-1/2} L^4.
2. **Powers of log in the minor arcs.** The minor-arc term is sup|G|^2 ∫|F|^2 ≪ N^2 P^{-1} L^8 · Y L = Z Y^2 L^{11-B}. The unbalanced-length cost is the factor Z/Y = L^2. With B = 3A + 12 this gives a total variance ≪ Z Y^2 L^{-3A-1}, and so an exceptional set ≪ Z L^{-A-1}.
3. **Major arcs.**
   - (SW) is applied at x ∈ [X^{1/2}, X] for X ∈ {Y, N}, so log x >= L/4 and q <= L^B <= (log x)^{B+1}.
   - The partial-summation loss is 1 + 2π|β|X <= 1 + 2πP for both sums, since X <= N.
   - Bookkeeping slip, found and fixed: K = 2B + 1 gives only X L^{-1}, so I took K = 3B + 12 to get X L^{-B-12}.
   - The error is then controlled in L^2 by sup|G - G*|^2 ∫|F|^2 + sup|F - F*|^2 ∫_M |G*|^2, with ∫_M |G*|^2 ≤ N Σ_{q<=P} μ^2/φ(q) ≪ N log P.
4. **Singular series.** I wrote a self-contained proof of Σ_{h<=Z} |S - S_P|^2 ≪ Z log P/P. It uses:
   - |c_q(h)| = φ((q,h)) for squarefree q;
   - the factorisation q = (q,h)·r;
   - Σ_{r<=X} μ^2 (r/φ(r))^2 ≪ X, via (n/φ(n))^2 = Σ_{e|n} k(e) with k(p) <= 6/p;
   - partial summation.

   No literature form of the Montgomery-Vaughan / Gallagher mean value is needed.
5. **Conversion to prime counts.** Higher prime powers contribute ≪ √N (log N)^2 = o(Y). Each prime pair has weight <= (log N)^2. With S(h) >= 2C2 > 1, this gives r_Y(h) >= Z/(4L^4) off the exceptional set.
6. **Numerics** (`experiments/src/c014_variance.c`, exact computation for all even h <= Z; raw output in `experiments/results/c014_variance/stdout.txt`).
   - The normalised variance mean((R-SY)/Y)^2 is 1.45e-2, 7.3e-3, 3.1e-3, 1.4e-3, 6.0e-4 for Z = 10^6, 3·10^6, 10^7, 3·10^7, 10^8.
   - The max relative deviation is 0.35, 0.27, 0.18, 0.13, 0.087.
   - The mean of S(h) is 2.0000.
   - min r_Y(h) = 1,692 at Z = 10^8.
   - Caveat: at these Z, the threshold Y L^{-A} for A >= 1 is below the square-root noise, so only A ≈ 1/2 can be probed. There the exceptional set drops to 0 by Z = 10^8.
